# EasyRead

Приложение для анализа читаемости русского текста и подготовки более понятной версии.

EasyRead выделяет длинные предложения, слова длиннее настраиваемого порога и формальные обороты из открытого словаря, показывает объяснимые рекомендации и позволяет сравнить исходный текст с отредактированной версией.

Интерфейс полностью на русском языке. Анализ выполняется локально по прозрачным правилам, без внешних API и моделей ИИ.

## Возможности

- вставка текста или загрузка UTF-8 `.txt` (до 1 МБ, до 50 000 символов);
- демонстрационные примеры;
- метрики: слова, предложения, средняя и максимальная длина, длинные слова, формальные выражения;
- учебный показатель **«Условный индекс простоты»** (0–100) с разбором штрафов;
- подсветка фрагментов с текстовыми метками;
- рекомендации и контекстные замены (только с подтверждением пользователя);
- сравнение двух версий и график Plotly;
- выгрузка упрощённого текста и автономного HTML-отчёта.

## Установка и запуск

Требуется Python 3.11+.

### Windows (PowerShell)

```powershell
cd EasyRead
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Если выполнение активации виртуального окружения запрещён политикой выполнения, выполните один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### macOS / Linux

```bash
cd EasyRead
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере (обычно `http://localhost:8501`).

## Как устроен анализ

1. **Предложения.** Сегментация учитывает распространённые сокращения (`г.`, `ул.`, `т.е.`, `т.д.`), инициалы и десятичные числа. Редкие сокращения и сложная прямая речь могут обрабатываться неточно.
2. **Слова.** Учитываются кириллические и латинские слова, в том числе с дефисом. Длинным считается слово с числом букв **больше** порога (по умолчанию 12). Длина — лишь грубый индикатор.
3. **Формальные выражения.** Поиск по словарю `content/replacements.json` с границами слова/оборота.
4. **Условный индекс простоты.** Старт 100; минус штраф за среднюю длину предложения; минус штраф за долю длинных слов; минус штраф за формальные выражения на 100 слов; результат ограничивается [0, 100]. Для пустого текста индекс не показывается.

Это **учебный** показатель на основе простых правил, а не валидированная оценка понимания текста. Он не указывает возраст читателя, школьный класс или сертифицированный уровень читаемости.

Подстановки из словаря — контекстные подсказки, а не генеративное переписывание и не гарантия сохранения смысла.

## Как проверять качество (для конференции / исследования)

1. **Проверка алгоритма.** Тексты с заранее известным числом предложений и слов (см. `tests/test_analyzer.py`).
2. **Сравнение «до / после».** Реальные отредактированные тексты: метрики и индекс пересчитываются теми же настройками на вкладке «Сравнение».
3. **Возможное исследование с читателями.** Отдельный этап: вопросы на понимание исходной и упрощённой версии. Изменение эвристики **не равно** доказательству лучшего понимания.

**Гипотеза:** выделение длинных предложений и формальных выражений может помочь автору подготовить более понятный учебный текст.

## Ограничения

- нет импорта PDF/Word в этой версии;
- правила не заменяют редактора-человека;
- длинный термин может быть уместен;
- словарь замен не универсален;
- введённый текст не сохраняется на диск автоматически.
